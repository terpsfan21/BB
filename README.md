# BB — Torvik totals error study

Question: are Torvik's pregame college-basketball totals wrong in a *systematic, predictable* way
(pace mismatch, roster change, shot profile, opponent style), and does any of that survive out of
sample against sportsbook closing totals? No totals model is built here — this is the evidence check
that comes first. **Read [`reports/FINDINGS.md`](reports/FINDINGS.md).**

## Phase 2 (market inefficiencies)

**Read [`reports/PHASE2.md`](reports/PHASE2.md).** The phase-1 model is frozen in `frozen/v1/` and is being
forward-tested on 2026-27 in `data/forward/` (append-only; `reports/forward_test.md`).

## Layout (phase 1)

| Path | What |
|---|---|
| `data/processed/games.parquet` | The dataset: 65,396 D1-vs-D1 games, 2014-15 … 2025-26, 142 columns |
| `reports/FINDINGS.md` | Conclusions, written by hand from the generated tables |
| `reports/results.md`, `results.json` | Every table, regenerated by `src/analyze.py` |
| `src/fetch_torvik.py` | Torvik schedules, box stats, player stats, daily rating snapshots |
| `src/fetch_espn.py` | ESPN event list + per-event sportsbook odds |
| `src/build_dataset.py` | Joins everything into `games.parquet` |
| `src/analyze.py` | Baseline, factor screen, walk-forward tests, market tests |

## Reproduce

```bash
pip install -r requirements.txt
python src/fetch_torvik.py        # ~2,000 small files, polite 4-way concurrency
python src/fetch_espn.py          # ~70k odds calls, cached per season
# SBR archive: download ncaa-basketball-2014-15 … 2020-21 .xlsx from
# sportsbookreviewsonline.com into data/raw/sbro/  (named 2014-15.xlsx etc.)
python src/build_dataset.py
python src/analyze.py
```

Raw downloads (~430 MB) are git-ignored.

## Dataset columns (main groups)

| Prefix / column | Meaning |
|---|---|
| `pre_t1_pts`, `pre_t2_pts`, `pre_total`, `pre_line` | Torvik's **frozen pregame** projection |
| `pre_poss_stored` / `pre_poss_recon` / `pre_poss` | Pregame projected possessions: stored by Torvik (2015-16 on) / rebuilt from day-before ratings (2014-15 only) / best available |
| `retro_*` | Torvik's projection **recomputed later with future ratings — leaky, never use for backtests** |
| `t1_pts`, `t2_pts`, `total`, `poss`, `poss_40`, `overtimes` | Actual result; `poss` includes overtime, `poss_40` is per 40 minutes |
| `t?_fgm … t?_pf` | Game box score |
| `t?_tm_*` | Torvik ratings from the snapshot dated the day before the game |
| `t?_s_*` | Season-to-date style/shot-profile rates from earlier games only, shrunk to league average (`o_` offence, `d_` allowed) |
| `t?_ret_min`, `t?_new_coach`, `t?_xp_*` | Share of last season's minutes returning, coaching change, ex-post minute composition |
| `sbr_close`, `sbr_open`, `espn_close`, `espn_open`, `espn_n_books` | Sportsbook totals by source |
| `close_total`, `close_source` | SBR close where available (2014-15 … 2020-21), otherwise ESPN multi-book median |
| `err_total`, `err_poss`, `err_poss_40`, `err_ppp` | Actual minus Torvik |
| `err_close`, `edge` | Actual minus close; Torvik minus close |

`team1` is the road team (first-listed at neutral sites), `team2` the home team.
